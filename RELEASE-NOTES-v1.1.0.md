# GregTech Odyssey — Friends Edition 1.1.0

В этой версии включены Chisel Reborn, Factory Blocks, Hang Glider, KleeSlabs,
Measurements, Pretty Rain и FramedBlocks. Остальные опциональные моды не
изменены.

> Сервер должен получить те же семь модов до подключения клиентов 1.1.0.
> Сначала обновите сервер, затем попросите игроков установить эту версию.

## Есть лицензия Minecraft

1. Скачайте `GTO-Friends-Licensed-Prism-Installer-v1.1.0.zip`.
2. Полностью распакуйте ZIP.
3. Закройте Minecraft и Prism.
4. Запустите `INSTALL-GTO-LICENSED.bat`.
5. При обновлении оставьте прежнюю папку установки.

Установщик содержит отдельный portable Prism Launcher и Java 21. При обновлении
с 1.0.4 аккаунт Prism, миры, серверы, настройки, скриншоты и карты Xaero
сохраняются.

## TLauncher

1. Скачайте `GTO-Friends-TLauncher-Installer-v1.1.0.zip`.
2. Полностью распакуйте ZIP.
3. Закройте Minecraft и TLauncher.
4. Запустите `INSTALL-GTO-TLAUNCHER.bat` и нажмите **Установить сборку**.
5. Полностью перезапустите TLauncher и выберите прежнюю игровую папку и
   локальную версию `1.20.1-forge-47.4.20`.

Установщик обновляет 1.0.2–1.0.4 на месте без полной переустановки и сохраняет
миры, серверы, настройки, скриншоты и карты Xaero. «Принудительное обновление»
в TLauncher должно быть выключено.

## Безопасное обновление

Оба установщика проверяют SHA-256 старых файлов, атомарно включают ровно семь
выбранных модов и после обновления строго сверяют весь клиент. Повторно
скачивать все моды не требуется.

Файлы `.sha256` рядом с архивами содержат контрольные суммы релиза.
